# Cloud & AI Simplified

A beginner-friendly, mobile-responsive learning website explaining AI infrastructure, cloud computing, data centers, and DevOps using plain-language examples.

## Features
- Responsive single-page site (HTML, CSS, JavaScript)
- Beginner-friendly AI infrastructure explainer
- Training vs. inference, cloud, data centers, GPUs, and DevOps lessons
- Interactive 4-question quiz
- Glossary and source links
- No build tools, framework, API key, or backend required

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a **public** GitHub repository, for example `cloud-ai-simplified`.
2. Upload `index.html` and `README.md` to the repository's root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for GitHub Pages to publish the site. The URL appears in the Pages settings and usually looks like:
   `https://YOUR-USERNAME.github.io/cloud-ai-simplified/`
